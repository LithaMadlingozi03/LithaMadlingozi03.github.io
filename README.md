# Projects & Process — Personal Portfolio

A responsive static portfolio website for GitHub Pages, showcasing software projects, data analysis, practical IT, and AI-assisted workflows.

## Pages
- `index.html` — portfolio homepage.
- `projects/screenpulse.html` — ScreenPulse social-media analytics case study.
- `AI_Workflow_Portfolio.html` — examples of AI-assisted analysis, development and troubleshooting.
- `AI_Workflow_Portfolio.md` — downloadable Markdown workflow record.
- `projects/it-operations.html` — sanitized IT troubleshooting workflow notes.
- `projects/java-swing-chat.html` — Java chat project, marked in progress.

## ScreenPulse files
The public repository includes the fictional source data and calculated metrics in CSV format, a format comparison chart (SVG), a Markdown report summary and the ScreenPulse AI workflow notes. The original Excel workbooks, PowerPoint/PDF files and supplied screenshot images have not been uploaded to this repository yet.

## Preview locally
Double-click `index.html` in a browser. To run a local server, open PowerShell in this folder and run:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000` and press Ctrl+C in PowerShell to stop the server.

## Publish through GitHub Pages
1. Open the repository settings: https://github.com/LithaMadlingozi03/LithaMadlingozi03.github.io/settings/pages
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Choose the `main` branch and the `/(root)` folder, then click **Save**.
4. When GitHub finishes deploying, open https://lithamadlingozi03.github.io/.

## Evidence and responsible presentation
ScreenPulse uses fictional data covering eight posts. The sample is useful for practice and hypothesis generation, but is not statistically conclusive and does not establish causation. Keep private information, credentials, internal network configuration, and school/client details out of the public repository.

AI was used to support parts of analysis, development, documentation and troubleshooting. Suggested outputs were reviewed against source data or actual environment results where available. Planned work is labelled as in progress and is not presented as implemented.
