# Portfolio publishing checklist

1. The static site source files are in this repository root, including index.html and styles.css.
2. Open Settings → Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select main and /(root), then click Save.
5. After deployment, visit https://lithamadlingozi03.github.io/ and test the homepage, ScreenPulse page, workflow page, navigation, chart and CSV downloads.
6. Keep original Excel and PowerPoint/PDF source files separate until you upload them through GitHub's file upload interface. Only publish files you have permission to share.

ScreenPulse is a fictional dataset of eight posts. IT troubleshooting notes are intentionally sanitised; do not publish credentials, student data, device identifiers or private system details.
