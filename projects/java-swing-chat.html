Java Swing Chat Application

A planned desktop chat application with a Swing interface and TCP socket communication, built in small stages.

Planned scope

  • Username entry (not real account authentication).
  • Swing login window and chat frame.
  • A TCP server that relays messages between connected clients.
  • Multiple clients, timestamps, connection notifications, Send button and Enter-to-send.

Current verified setup

  • Windows and Visual Studio Code.
  • Java 23.0.2 is installed.
  • java --version and javac --version work in PowerShell.
  • mvn --version returned that Maven was not recognised. Maven installation is the next step.

Planned milestones

  1. Install Maven and verify it.
  2. Create the project scaffold and launch a minimal Swing window.
  3. Add the login and chat interface.
  4. Build server/client socket communication.
  5. Test multiple clients and document the results.
This is not a working chat application yet. Update the status as features are implemented and checked.
