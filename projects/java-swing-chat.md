# Java Swing Chat Application — In Progress

Planned Java desktop application using Swing and TCP sockets. Proposed scope includes username entry (not real authentication), a chat window, a relay server, multiple clients, timestamps and connection notifications.

Verified setup so far: Java 23.0.2 and javac work in PowerShell. Maven was not recognised as a command, so Maven installation is the next milestone.

This is a setup-stage project, not a working chat application yet. Update this page only after features are implemented and tested.
