# IT Infrastructure and Device Management

This portfolio note documents AI-assisted planning and troubleshooting around Windows Server migration and network configuration, plus planning a staged update process for 106 managed iPads.

The working method was to provide current evidence, take one safe and actionable step, then verify actual environment output before proceeding. It does not claim that the migration was completed or that every device update succeeded.

Keep school names, credentials, student data, device identifiers and private network configuration out of the public portfolio.
